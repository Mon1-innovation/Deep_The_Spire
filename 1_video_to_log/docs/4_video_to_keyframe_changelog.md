# Changelog

## [Unreleased] - 2026-09-21

### Added

- 新增黑屏与近黑转场帧检测，支持配置平均亮度、标准差和暗像素比例阈值。
- 新增 `combat_hand` ROI，用于关注战斗中的手牌和出牌相关区域。
- 新增 `event_options` ROI，用于关注问号事件的选项面板。
- 新增普通 ROI、战斗 ROI 和事件选项 ROI 的独立变化阈值，可在 `config/sts2_720p.json` 中调整。

### Changed

- 提高默认扫描频率，以降低短暂出牌动作被漏检的概率。
- `combat_hand` 和 `event_options` 使用低于普通页面检测的变化阈值，即使全屏画面变化不明显，局部变化也可以触发候选关键帧。
- 候选帧继续通过单次顺序解码流程生成，不再依赖先切分视频再合并结果。

### Fixed

- 修复转场黑屏被周期锚点或候选帧保留的问题。
- 修复问号事件选项选择前后画面变化较小，导致关键决策帧容易遗漏的问题。
- 修复战斗出牌局部变化被全屏变化阈值过滤的问题。

### Compatibility

- `frame_index` 与 `keyframes.jsonl` 的记录顺序继续保持与原视频一致。
- pHash/SSIM 去重逻辑保持不变，用于减少重复的稳定画面。
- 脚本仍只负责保留图像证据和来源信息，不判断具体游戏语义；出牌、问号事件及其他事件的识别由后续流程负责。
